The 4 Friday Questions
Q1
What did I repeat this week?
List every task you did more than twice. Any task you repeat more than 3 times per week should not be done by a human. It's an automation candidate.
→ Write the list. Circle the most painful one.
Q2
What took longer than it should have?
Time you resent spending is time a system should own. If you felt frustrated while doing a task, that frustration is data — it's telling you the task doesn't deserve your attention.
→ Name it. Is it automatable? If yes — that's next week's build.
Q3
What would disappear if X ran automatically?
Name the outcome you want. Then work backwards. "If follow-up emails went out automatically — I'd never lose a warm lead again." That outcome is the goal. The n8n workflow is the path.
→ Write the outcome. Then design the 3-node workflow that achieves it.
Q4
What's the ONE system I'll build this weekend?
Not two. Not a list. One. Pick the task from Q1 or Q2 that causes the most friction. Build the simplest version of a system that eliminates it. Use it on Monday.
→ Write it down. Block 2 hours on Saturday. Ship it.
